# Gmail הקלטה מצורפת

תוסף Chrome שמוסיף לחלון כתיבת אימייל ב-Gmail:

- **🎤 הקלטה** – הקלטה קולית שמומרת ל-MP3 ומצורפת לאימייל.
- **גזירת מסך** – פותח את כלי הגזירה של Windows (כמו Win+Shift+S), והגזירה נכנסת לבד לתוך גוף האימייל, במקום הסמן. בפעם הראשונה Chrome שואל אם לפתוח את כלי הגזירה – מסמנים "תמיד לאפשר".
- **וידאו מסך** – הקלטת וידאו של המסך עם קול מהמיקרופון, מצורפת כ-WebM בתוך ZIP (עד 10 דקות, כ-11MB לדקה).

## התקנה
1. הורד את `gmail-voice-attach.zip` מעמוד ה-Releases וחלץ לתיקייה קבועה.
2. פתח `chrome://extensions` והפעל **Developer mode**.
3. לחץ **Load unpacked** ובחר את התיקייה.
4. רענן את Gmail ופתח "כתיבה".

ההמרה ל-MP3 נעשית עם [lamejs](https://github.com/zhuker/lamejs) 1.2.1 (LGPL-3.0), כלול ב-`vendor/`.
